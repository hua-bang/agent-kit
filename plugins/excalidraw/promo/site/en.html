How it works

  1. Ask in chat

    Describe what you want. The drawing appears in the conversation as a card you can edit.

  2. Draw together

    Sketch on it yourself, then ask the agent to build on it. Your shapes stay where you put them.

  3. Find it later

    Every drawing is a file on your computer, and the whole library opens from the sidebar.

Install in Codex

Two commands. Needs Node 22 or later on your PATH. They change your Codex plugin settings.

codex plugin marketplace add hua-bang/agent-kit --ref release
codex plugin add excalidraw@agent-kit-local

Then start a new session and ask: “Use the excalidraw plugin and open my drawings.” Drawings are saved in ~/.excalidraw-plugin/.

Status: tested locally with the real plugin and the official MCP Apps bridge; not yet verified inside Codex desktop, ChatGPT or Claude.
