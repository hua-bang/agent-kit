从一张流程图，到一整本书

四张图，由浅到深。每张都是插件里的真实截图，只用一句话生成。

  2. 讲清一份财报 02

  3. 读懂一篇论文 03

    「《Attention Is All You Need》到底讲了什么？」

  4. 拆一整本书 04

怎么用

  1. 在对话里说

    说出你想要的图，它会以一张可编辑的卡片出现在对话里。

  2. 一起画

    你可以自己动手画，再让 AI 接着改，你画的部分不会被动。

  3. 随时找回

    每张图都是你电脑上的文件，从侧边栏就能打开整个图纸库。

安装到 Codex

两条命令。需要 PATH 中有 Node 22 或更新版本。这两条命令会修改你的 Codex 插件配置。

codex plugin marketplace add hua-bang/agent-kit --ref release
codex plugin add excalidraw@agent-kit-local

装好后开一个新会话，对 Agent 说：「使用 excalidraw 插件，打开我的图纸库。」图纸保存在 ~/.excalidraw-plugin/。
